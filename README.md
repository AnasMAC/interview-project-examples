# Ostorlab Interview Project Examples

This repository contains examples of the kind of projects that are typically used in the interview process at [Ostorlab](https://www.ostorlab.co).

These projects are **examples only**. They are retired and will not be used in any future Ostorlab interview process. You can browse them to understand what our exercises look like, how they are structured and what we usually expect from candidates.

All companies, people, products, credentials and events in these projects are fictional.

## Contents

| Folder | Format |
| --- | --- |
| [`01-24h_projects`](01-24h_projects) | Take-home exercises with a 24-hour window. AI tools are allowed. |
| [`02-interview_projects`](02-interview_projects) | One-hour projects worked on live during an interview call. AI tools are expected. |

Each project folder holds a `README.md` with the brief and the material needed to work on it.
