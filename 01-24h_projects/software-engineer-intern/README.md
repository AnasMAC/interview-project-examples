# Software Engineer Intern: AI-enabled 24-hour exercises

Assign **one** package to a candidate. Each is independent, offline and has a **24-hour** window; candidates are not expected to work the full 24 hours. The candidate receives an invitation email with a start link: clicking Start begins the 24 hours and unlocks the package zip. Do not expect overnight availability or surprise messages. No AI tool is provided; AI is encouraged, no purchase is required, and free/offline or no-AI completion is supported.

All company/product behavior, tenants and records are explicitly fictional assessment facts. Inputs are supplied and authoritative. No real accounts, production access, external research, scans, outreach or deployment are required. Each candidate directory includes Python 3.10+ standard-library CLI scaffolding, two usable fixture files, intentionally malformed input, and starter smoke checks. **The assessed feature is deliberately unfinished**, with an explicit exit-3 placeholder; passing smoke checks confirms setup, not a completed exercise.

Export only the chosen **candidate/** directory (including its hidden .gitignore), never evaluator material. For example, from the chosen package directory: `zip -r /tmp/software-engineer-intern-exercise.zip candidate`. Run the exported starter and smoke checks before sending the invitation. Each staff guide includes the exact commands, fixture truth, role-specific acceptance checks, score anchors, scope rationale and an optional AI-permitted follow-up question.

**Evaluator files are visible to repository readers. This private exercise bank is not a confidential test.** Ownership can be checked with each guide's optional follow-up question in a later interview; do not depend on secrecy, AI detectors or prompt-history access.

Candidates submit an archive/repo with runnable code and tests, an execution guide, concise evidence-linked decision log, AI-use note, and recording or accessible text walkthrough. Full marks are possible on the core alone. Published weights are usable result 40, accuracy/verification 25, prioritization 20, communication/handoff 15; each dimension is anchored 0–4. The assessment observes bounded follow-through, integration and verification, not hours worked, willingness to sacrifice sleep, prose polish or a scientific measure of motivation.
