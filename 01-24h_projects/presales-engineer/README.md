# Pre-Sales Engineer: AI-enabled 24-hour exercise bank

Assign **one** package per candidate. The candidate receives an invitation email with a start link; clicking Start begins their 24 hours and unlocks the package zip. Candidates are not expected to work the full 24 hours and organize their own time within the window. No AI tool is provided; candidates may use their own. The clock assesses bounded execution, integration and verification. It does not scientifically measure motivation or reward sacrificing sleep.

This bank is used for the Pre-Sales Engineer role. The packages expect working application security knowledge (static vs dynamic analysis, common web and mobile vulnerability classes, false positives, authenticated scanning) and familiarity with CI/CD configuration. No package requires programming: scripts are always optional and earn no extra marks. Reading JSON, YAML and CSV is a baseline skill.

All companies, people, product features, prices and events are fictional assessment facts, including the vendor Lantern. Supplied fixtures are authoritative. No real outreach, scanning, accounts, purchases or production systems are involved. Free spreadsheets and text editors are sufficient; candidates may use their own AI tools.

The zip contains **only the assigned `candidate/` directory**, keeping its folder structure. Open the exported README and links locally before sending. Staff keep `evaluator/README.md` and use its launch checklist, fixture truth, scoring anchors and optional follow-up question.

Evaluator files are visible to repository readers: this private exercise bank is **not a confidential test**. Never send staff material with the candidate export. If a candidate is invited to a later interview, the optional follow-up question in each guide helps check ownership, with AI allowed.

The published score is usable result 40, accuracy/verification 25, prioritization 20, and communication/handoff 15. Score each dimension 0–4; total = sum(weight × score / 4), out of 100. Full marks are available on the core alone. A promise of a feature, date or certification the product facts do not support is an accuracy defect in every package. Do not grade AI detection, preferred software, prose polish, hours worked or output volume.
