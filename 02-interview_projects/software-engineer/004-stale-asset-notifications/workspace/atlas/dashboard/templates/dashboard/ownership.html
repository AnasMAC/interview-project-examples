Ownership rules

How an owner is chosen

  1. Enabled rules are tried in order of priority (lower first); rules with the same priority go oldest first.
  2. The first matching rule sets the owner team. A more specific pattern further down does not override it.
  3. hostname patterns are shell globs on host and domain keys; * also matches dots, so *.{{ org.domain }} covers every subdomain level.
  4. cidr matches IP assets inside the network and networks contained in it; tag matches assets carrying the tag.
  5. Owners set by hand are locked and never changed by rules. An asset that matches no rule becomes unowned.
